# Hi, I'm Bilge 👋

Computer Engineering MSc student at **Ankara University**. I work on machine learning for medical imaging, and I build iOS apps on the side.

🔬 **Currently:** my thesis on rare disease detection with limited data. I'm using few-shot learning and generative augmentation (GANs, diffusion models) to detect systemic sclerosis from nailfold videocapillaroscopy images.
